Gate certificates

The certificate is the proof.

A gate certificate carries the answers, the evidence and the decision rule. Anyone recomputes the verdict locally: no database, no engine, no call home.

Each failure has a named reason, from bad-signature to expired. Expiry is the only revocation, by design.
